# M4 — Manufacturing Release

Implements #47–#49, #51–#56, #73 and #76: revision-bound STEP validation, an optional
FreeCAD MCP profile and mechanical constraint model, manufacturing profile schema and
measured-feature rules, a complete artifact manifest, two-phase deterministic release,
export consistency tests, actual Gerber SVG rendering, minimal-spec blocked-release
end-to-end coverage and an honest engineering walkthrough.

The release coordinator executes independent checks and matches native stackup/BOM.
It will not accept a weak mandatory gate configuration, skipped/failed evidence or
pre-approval of future Gerber outputs. Finalization requires fresh signed artifact review
and verifies source/artifact hashes. No upload/order side effect exists.

Tests distinguish synthetic exporter/approval contracts from actual KiCad 10 export,
STEP and Gerbonara 1.6.3 rendering qualification. Current JLCPCB manufacturing parameters
are not qualified by the sample profile. FreeCAD installation was attempted through the
host Fedora repositories and was unavailable; its optional MCP profile remains disabled.
No board has been manufactured or approved for fabrication in this milestone.
