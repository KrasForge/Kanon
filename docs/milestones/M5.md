Tests include counterexamples for missing/invalid evidence, voltage/domain conflicts,
reserved/dedicated pins, incomplete alternate qualification, unknown op-amp stability,
MCP mutation requests and actual STEP overlap/separation and KiCad rendering.
Research issues deliver findings and experiment plans, not a claim that return-path
analysis, unattended PDF ingestion or automatic critical-net routing is solved.

These modules do not provide a vendor FPGA database, live GPT model transport, automatic
board-to-all-audits extraction or a validated populated PCB. The issue backlog remains
open for engineering acceptance and qualification; code and configuration alone do not
close it. Exact integration limits are recorded in docs/integrations.md and capabilities.md.
