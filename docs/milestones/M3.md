# M3 — Agentic PCB Designer orchestration

Implements orchestration and declared-layout scope for #36–#41 and #43–#44:
legal lifecycle transitions with current signed gate evidence; validated role policies
and restricted tool dispatch; frozen independent review packets; stable-finding
remediation/reverification; critical-net class coverage; floorplanning and quantified
placement checks including native footprint-anchor extraction.

Tests exercise illegal/stale/unsigned transitions, signed independent approval, policy
escalation attempts, mutable response isolation, designer self-review rejection, missing
review scope, no automatic approval, stable IDs and stale remediation refusal, incomplete
critical-net topics, and geometric distance boundaries. Reviewer callbacks in tests are
synthetic. This milestone does not claim a live model has designed or approved a PCB.

See docs/agent-workflow.md for API use and exact limitations. All tracking issues remain
open; no scope is considered complete solely because configuration exists.
